Help
How it works, and how to check that it is right.

  

    
Is my data safe?
Yes. The page is static: the export is read and the workbook is made inside your browser tab. Nothing is uploaded or stored, and closing the tab removes it. Without internet, use the offline copy (link at the top, under "How to check").

    
Which format will I get?
The APQR format QA shared as the reference. For product 30000838 (MBR F1M00011) it is filled by rules checked value by value against that reference. Every other product gets the same style with the same columns: a cell is filled only where PAS-X has that exact value, otherwise it stays blank. No average (Ave) values are written.

    
How do I check a value?
Click any cell in the preview: it shows the PAS-X step code, the parameter code, the readings and the calculation. The workbook carries the same detail in its sheet APQR_Source_Trace.

    
What stays blank?
Values PAS-X does not hold as numbers (printout readings such as thickness and hardness, LIMS results), and any value the rules cannot prove. Each one is listed with its reason in the sheet APQR_Exceptions.

    
Other ways to run it
Command line: python final/apqr_curate.py export.xlsx. Plant portal: start_portal.bat on one server, for a shared store of exports. Automatic sync: data sync and Microsoft Fabric.

    
Status
Prototype for QA review. Verify against the batch record before use in a GMP APQR. Not a validated system.
