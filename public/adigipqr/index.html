Parameters, capability and trend signals

Cpk = min(USL − mean, mean − LSL) / 3σ with σ = average moving range / 1.128 (batch-to-batch); Ppk uses the overall SD. Not interpreted below 6 batches. Signals: R1 point beyond 3σ, R2 nine points on one side, R3 six points rising or falling.

CPP values from scanned BMR pages

Printouts from equipment that is not connected to PAS-X sit at the end of the BMR. This page reads them in the browser (open-source OCR, nothing uploaded), checks every record against itself, and adds the records you accept to the APQR Excel.

Read today

Individual Weight Variation Record (balance printout): batch, serial, interval, side, balance, limits, n, average, min, max, SD and every individual weight.

How a value is trusted

The individual weights must reproduce the printed n, min, max, range, average and SD; Min %/Max % must follow; the printed result must agree with the limits; the limits must be the average or standard weight ± 5 / 7.5 / 10 %; serial numbers must rise with time. Records that fail any check need a person to compare them with the page before they can be accepted.

SQL for the MES team

Fills the parameter block of the APQR extraction query. Run it read-only with the MES reporting account (see the project README), export the grid as CSV, and drop the file on the APQR sheet tab.

Guides

Three ways to run the same conversion, and the path from manual exports to an automatic data sync.

1 · This page (online or offline)

Everything runs in the browser. Offline: copy the web folder to a PC or share and run start_web_app.bat (a local web server on 127.0.0.1); the APQR sheet tab also works by double-clicking index.html.

2 · Plant portal (shared store)

start_portal.bat on one plant server: the MES team loads exports once, QA picks a material and dates and downloads. Adds server-side BMR scan reading (RapidOCR) and an optional read-only nightly pull from PAS-X.

3 · Command line

python python/apqr_pivot.py export.csv or drag the export onto build_apqr.bat. Same workbook.

4 · Automatic data sync

Step-by-step in Data sync and Microsoft Fabric: scheduled read-only pull first (no licence, data stays on-prem), Fabric pipeline + Lakehouse when the company wants one data platform.
